# 2.35.x Release Series

Pants is an open-source project that is not owned or controlled by any one company or organization, and does incur some expenses. These expenses are managed by Pants Build, a non-profit that was established for this purpose. This non-profit's only source of revenue is [sponsorship](https://www.pantsbuild.org/sponsorship) by individuals and companies that use Pants.

We offer [formal sponsorship tiers for companies](https://www.pantsbuild.org/sponsorship), as well as individual sponsorships via [GitHub](https://github.com/sponsors/pantsbuild).

#### Javascript

Dependency inference now finds the owner of an imported file that is not a JavaScript or TypeScript module, such as `import "./index.css"` or `import rows from "./rows.json"`: the target that owns that exact file (for example a `resources` or `files` target) becomes a dependency. Previously such imports were only tried with a JavaScript or TypeScript extension appended, so they were always reported as unowned.

An import with a bundler's query, such as `import source from "./App.tsx?raw"` or `import logo from "./logo.svg?url"`, is now inferred from the file before the `?`. Previously the query was taken as part of the file name, so the import was reported as unowned.

#### TypeScript

A TypeScript import that names the JavaScript file a source compiles to, such as `import { x } from "./errors.js"` for `errors.ts` (TypeScript's [file extension substitution](https://www.typescriptlang.org/docs/handbook/modules/reference.html#file-extension-substitution)), is now inferred as a dependency on that `.ts`, `.tsx` or `.d.ts` source. `.jsx` maps to `.tsx`. Previously only a file with the exact `.js` name was looked for.
